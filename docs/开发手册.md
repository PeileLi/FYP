# 开发手册 / Development Guide

## 概述 / Overview

本指南将帮助您在新电脑上设置和继续开发这个基于 Hyperledger Fabric 的区块链众筹平台项目。

This guide will help you set up and continue developing this blockchain crowdfunding platform project based on Hyperledger Fabric on a new computer.

---

## 📋 系统要求 / System Requirements

### 必需软件 / Required Software

- **Docker** (版本 20.10+) 和 **Docker Compose** (版本 2.0+)
- **Git** (版本 2.0+)
- **Java** JDK 17 或更高版本（用于本地开发后端）
- **Maven** 3.6+（用于本地开发后端）
- **Node.js** 18+ 和 **npm**（用于本地开发前端）
- **Go** 1.22+（用于链码开发）

### 系统资源 / System Resources

- 至少 8GB RAM
- 至少 20GB 可用磁盘空间
- 支持虚拟化的 CPU（用于 Docker）

## 🚀 快速开始 / Quick Start

### 步骤 1: 克隆项目 / Step 1: Clone the Project

```bash
# Clone the repository
git clone https://github.com/PeileLi/FYP.git
cd FYP

# Initialize and update git submodules (重要！/ Important!)
git submodule update --init --recursive
```

**注意 / Note:** `fabric/fabric-samples` 是一个 git 子模块，必须初始化才能使用。

### 步骤 2: 安装 Hyperledger Fabric / Step 2: Install Hyperledger Fabric

```bash
# Navigate to fabric directory
cd fabric

# Download Fabric samples and binaries
curl -sSL https://bit.ly/2ysbOFE | bash -s

# This will install:
# - fabric-samples
# - Fabric binaries (peer, orderer, etc.)
# - Fabric Docker images
```

**注意 / Note:** 如果您的项目已经包含 `fabric-samples` 子模块，此步骤可能只需要安装二进制文件和 Docker 镜像。

### 步骤 3: 配置路径 / Step 3: Configure Paths

项目中有一些硬编码的路径需要根据您的新电脑路径进行更新。

There are some hardcoded paths in the project that need to be updated according to your new computer's path.

#### 3.1 更新 docker-compose.yml

编辑 `docker-compose.yml` 文件，更新第 57-58 行的路径：

Edit `docker-compose.yml` file, update paths on lines 57-58:

```yaml
volumes:
  # 将 /home/li/project/FYP 替换为您的实际项目路径
  # Replace /home/li/project/FYP with your actual project path
  - /your/actual/path/to/FYP/fabric/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com:/fabric/organizations/peerOrganizations/org1.example.com:ro
  - /your/actual/path/to/FYP/fabric/fabric-samples/test-network/organizations/ordererOrganizations/example.com:/fabric/organizations/ordererOrganizations/example.com:ro
```

**快速方法 / Quick Method:**

```bash
# 获取当前项目绝对路径
PROJECT_PATH=$(pwd)

# 使用 sed 替换路径（Linux/Mac）
sed -i "s|/home/li/project/FYP|${PROJECT_PATH}|g" docker-compose.yml
```

#### 3.2 更新 application.yml（可选，如果本地开发）

如果您要在本地运行后端（不使用 Docker），需要更新 `backend/src/main/resources/application.yml`：

If you want to run the backend locally (without Docker), update `backend/src/main/resources/application.yml`:

```yaml
fabric:
  cert-path: ${FABRIC_CERT_PATH:/your/actual/path/to/FYP/fabric/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp/signcerts/cert.pem}
  key-path: ${FABRIC_KEY_PATH:/your/actual/path/to/FYP/fabric/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp/keystore}
  tls-cert-path: ${FABRIC_TLS_CERT_PATH:/your/actual/path/to/FYP/fabric/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/peers/peer0.org1.example.com/tls/tlscacerts/tls-localhost-7054-ca-org1.pem}
```

**注意 / Note:** 如果使用 Docker Compose，这些路径会在容器内通过环境变量设置，不需要修改。

### 步骤 4: 启动 Hyperledger Fabric 网络 / Step 4: Start Hyperledger Fabric Network

```bash
# Navigate to test-network directory
cd fabric/fabric-samples/test-network

# Start the network and create channel
./network.sh up createChannel -c mychannel -ca

# 验证网络是否运行
docker ps
```

您应该看到以下容器运行：
- peer0.org1.example.com
- peer0.org2.example.com
- orderer.example.com
- ca_org1, ca_org2, ca_orderer

### 步骤 5: 部署链码 / Step 5: Deploy Chaincode

```bash
# 返回项目根目录
cd ../../../..

# 使用部署脚本（推荐）
chmod +x chaincode/deploy.sh
./chaincode/deploy.sh

# 或者手动部署
cd fabric/fabric-samples/test-network
./network.sh deployCC -ccn donation -ccp ../../../chaincode -ccl go -ccv 1.0 -ccs 1
```

**部署脚本参数说明 / Deploy Script Parameters:**

```bash
./chaincode/deploy.sh [链码名称] [链码路径] [语言] [版本] [序列号] [通道名称]

# 默认值：
# 链码名称: donation
# 链码路径: 项目根目录/chaincode
# 语言: go
# 版本: 1.0
# 序列号: 1
# 通道名称: mychannel
```

### 步骤 6: 创建 Docker 网络 / Step 6: Create Docker Network

后端需要连接到 Fabric 网络，确保创建了外部网络：

The backend needs to connect to the Fabric network, ensure the external network is created:

```bash
# 创建 fabric_test 网络（如果不存在）
docker network create fabric_test
```

### 步骤 7: 启动应用 / Step 7: Start the Application

#### 方式 1: 使用 Docker Compose（推荐）

```bash
# 在项目根目录
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

#### 方式 2: 本地开发

**启动后端 / Start Backend:**

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

**启动前端 / Start Frontend:**

```bash
cd frontend
npm install
npm run dev
```

### 步骤 8: 验证安装 / Step 8: Verify Installation

1. **检查后端 / Check Backend:**
   ```bash
   curl http://localhost:8080/api/health
   # 或访问
   # http://localhost:8080
   ```

2. **检查前端 / Check Frontend:**
   - 访问 http://localhost:3000（Docker）或 http://localhost:5173（本地开发）

3. **检查区块链连接 / Check Blockchain Connection:**
   ```bash
   # 查询链码
   cd fabric/fabric-samples/test-network
   ./network.sh cc query -c mychannel -ccn donation -ccqc '{"function":"ReadCampaign","Args":["CAMP001"]}'
   ```

## 📝 常用命令 / Common Commands

### Fabric 网络管理 / Fabric Network Management

```bash
cd fabric/fabric-samples/test-network

# 启动网络
./network.sh up createChannel -c mychannel -ca

# 停止网络
./network.sh down

# 清理所有数据（包括链码数据）
./network.sh down -v

# 查看网络状态
docker ps
```

### 链码操作 / Chaincode Operations

```bash
# 查询链码
./network.sh cc query -c mychannel -ccn donation \
  -ccqc '{"function":"ReadCampaign","Args":["CAMP001"]}'

# 调用链码
./network.sh cc invoke -c mychannel -ccn donation \
  -ccic '{"function":"CreateCampaign","Args":["CAMP001","Alice","2024-01-20T10:00:00","Test Campaign","AUTO_APPROVED"]}'

# 更新链码（修改代码后）
./network.sh deployCC -ccn donation -ccp ../../../chaincode -ccl go -ccv 1.1 -ccs 2
```

### Docker 操作 / Docker Operations

```bash
# 查看运行中的容器
docker ps

# 查看日志
docker logs fyp-backend
docker logs fyp-frontend
docker logs fyp-postgres

# 重启服务
docker-compose restart backend

# 查看网络
docker network ls
docker network inspect fabric_test
```

## 🐛 故障排除 / Troubleshooting

### 问题 1: Git 子模块未初始化

**症状 / Symptoms:** `fabric/fabric-samples` 目录为空

**解决方案 / Solution:**
```bash
git submodule update --init --recursive
```

### 问题 2: Docker 网络不存在

**症状 / Symptoms:** `Error: network fabric_test not found`

**解决方案 / Solution:**
```bash
docker network create fabric_test
```

### 问题 3: 路径错误导致后端无法连接 Fabric

**症状 / Symptoms:** 后端启动时 Fabric 连接失败

**解决方案 / Solution:**
1. 检查 `docker-compose.yml` 中的路径是否正确
2. 确保 Fabric 网络已启动
3. 检查证书文件是否存在：
   ```bash
   ls -la fabric/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp/signcerts/
   ```

### 问题 4: 端口冲突

**症状 / Symptoms:** 端口已被占用

**解决方案 / Solution:**
- 修改 `docker-compose.yml` 中的端口映射
- 或停止占用端口的服务

### 问题 5: 链码部署失败

**症状 / Symptoms:** 链码部署时出错

**解决方案 / Solution:**
```bash
# 清理并重新部署
cd fabric/fabric-samples/test-network
./network.sh down
./network.sh up createChannel -c mychannel -ca
./network.sh deployCC -ccn donation -ccp ../../../chaincode -ccl go -ccv 1.0 -ccs 1
```

### 问题 6: 数据库连接失败

**症状 / Symptoms:** 后端无法连接数据库

**解决方案 / Solution:**
1. 确保 PostgreSQL 容器正在运行：`docker ps | grep postgres`
2. 检查环境变量配置
3. 查看数据库日志：`docker logs fyp-postgres`

## 💡 提示 / Tips

1. **路径配置:** 使用环境变量或相对路径可以避免在不同电脑上修改配置
2. **Docker 镜像:** 首次运行会下载大量 Docker 镜像，请确保网络畅通
3. **数据持久化:** Docker volumes 会保存数据库和上传的图片数据
4. **链码更新:** 更新链码时需要递增版本号和序列号
5. **网络隔离:** Fabric 网络使用独立的 Docker 网络，确保网络名称正确
