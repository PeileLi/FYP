## 🔧 关键技术实现

### 1. Docker Compose 相对路径

```yaml
services:
  backend:
    volumes:
      # 相对路径 - Docker Compose 自动解析
      - ./fabric/fabric-samples/test-network/organizations/...:/fabric/...
```

**工作原理：**
- Linux: `$PWD/fabric/...` → `/fabric/...`
- Mac: `$PWD/fabric/...` → `/fabric/...`
- 容器内统一使用 `/fabric/...`

### 2. Shell 脚本自动检测

```bash
# 自动检测脚本所在目录
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

# 计算项目根目录（相对于脚本位置）
PROJECT_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"

# 自动检测操作系统
if [[ "$OSTYPE" == "darwin"* ]]; then
    OS_TYPE="Mac"
elif [[ "$OSTYPE" == "linux-gnu"* ]]; then
    if grep -qi microsoft /proc/version 2>/dev/null; then
        OS_TYPE="WSL"
    else
        OS_TYPE="Linux"
    fi
fi
```

### 3. 环境变量优先级

```env
# .env 文件（用户配置，优先级最高）
FABRIC_CERT_PATH=/fabric/organizations/.../cert.pem

# application.yml（默认值，优先级最低）
cert-path: ${FABRIC_CERT_PATH:/fabric/organizations/.../cert.pem}

# docker-compose.yml（卷挂载，连接宿主机和容器）
volumes:
  - ./fabric/fabric-samples/...:/fabric/...
```

### ✅ 推荐做法

1. **使用相对路径**
   ```yaml
   volumes:
     - ./app:/app
   ```

2. **使用脚本自动检测**
   ```bash
   SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
   ```

3. **使用环境变量**
   ```env
   FABRIC_CERT_PATH=/fabric/...
   ```

4. **提供模板文件**
   ```bash
   cp .env.example .env
   ```

### ❌ 避免的错误

1. **硬编码绝对路径**
   ```yaml
   # ❌ 错误
   volumes:
     - /home/user/project:/app
   ```

2. **假设特定目录结构**
   ```bash
   # ❌ 错误
   cd /home/user/project
   ```

3. **直接在代码中使用主机路径**
   ```java
   // ❌ 错误
   String certPath = "/home/user/project/fabric/...";
   ```
