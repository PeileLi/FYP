## 🚨 常见陷阱

### ❌ 避免这些错误

1. **不要使用绝对路径**
   ```yaml
   # ❌ 错误
   volumes:
     - /home/user/FYP/fabric/...
   
   # ✅ 正确
   volumes:
     - ./fabric/...
   ```

2. **不要硬编码用户名**
   ```bash
   # ❌ 错误
   cd /home/li/project/FYP
   
   # ✅ 正确
   cd "$(dirname "$0")/.."
   ```

3. **不要假设特定目录结构**
   ```bash
   # ❌ 错误
   if [ -d "/home/li/project/FYP" ]; then
   
   # ✅ 正确
   if [ -d "${PROJECT_ROOT}" ]; then
   ```

4. **不要在文档中使用特定路径**
   ```markdown
   <!-- ❌ 错误 -->
   进入 /home/li/project/FYP 目录
   
   <!-- ✅ 正确 -->
   进入项目根目录
   cd /path/to/FYP  # 替换为你的实际路径
   ```

## 📊 改进对比

### 之前（硬编码版本）

```yaml
# docker-compose.yml
volumes:
  - /home/li/project/FYP/fabric/...:/fabric/...
```

```bash
# start-fabric.sh
PROJECT_ROOT="/home/li/project/FYP"
TEST_NETWORK_DIR="/home/li/project/FYP/fabric/fabric-samples/test-network"
```

**问题：**
- ❌ 只能在特定位置工作
- ❌ 不同用户需要修改配置
- ❌ 不支持 Mac
- ❌ 项目移动后失效

### 现在（跨平台版本）

```yaml
# docker-compose.yml
volumes:
  - ./fabric/...:/fabric/...
```

```bash
# start-fabric.sh
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"
TEST_NETWORK_DIR="${PROJECT_ROOT}/fabric/fabric-samples/test-network"
```

**优势：**
- ✅ 任何目录都能工作
- ✅ 自动适配所有用户
- ✅ 支持 Linux/WSL/Mac
- ✅ 项目可随意移动
