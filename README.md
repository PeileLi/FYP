# 🌐 Blockchain Crowdfunding Platform

## 🧩 Project Description
The project is based on **Hyperledger Fabric** a blockchain crowdfunding donation platform that aims to achieve donation transparency and fund traceability.

### tech stack
- Blockchain: Hyperledger Fabric  
- Smart Contract: Go  
- Backend: Spring Boot + Java  
- Frontend: React  
- Database: PostgreSQL 
- Identity: Fabric CA  

---

## 📁 Project structure

```
FYP/
├── backend/          # Spring Boot backend service
├── frontend/         # React frontend application
├── chaincode/        # Hyperledger Fabric smart contracts (Go)
├── fabric/           # Fabric samples (git submodule)
├── docker-compose.yml # Docker compose configuration
└── README.md
```
