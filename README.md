# 🌐 Blockchain Crowdfunding Platform

## 🧩 Project Description
The project is based on **Hyperledger Fabric** a blockchain crowdfunding donation platform that aims to achieve donation transparency and fund traceability.

### tech stack
- Blockchain: Hyperledger Fabric  
- Smart Contract: Go  
- Backend: Spring Boot + Java  
- Frontend: Vue.js  
- Storage: IPFS  
- Identity: Fabric CA
